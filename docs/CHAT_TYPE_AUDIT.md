# Проверка типов чатов и результатов действий

20 октября 2026, целевое ядро 60 / 0.3.40.

| Модуль | Найденная проблема | Исправление |
| --- | --- | --- |
| administration | Знак ID, фиктивное выполнение | Реальный peer и MTProto-запросы через ядро |
| moderation | Положительная группа могла стать ЛС при совпадении ID | `chat_type`, без сетевого кеша и эвристик |
| mass_notifier | Все положительные ID отвергались | Явная проверка GROUP/CHANNEL |
| banall | Не проверялся тип чата, число запросов выдавалось за результат | Проверка peer, честное сообщение об очереди |
| RP | Пустой кеш обходил проверку публичного доступа группы | Тип из ядра; UNKNOWN не исполняется |
| Silent Tags | ЛС определялись по ID и неполному кешу | Тип из ядра |
| AFK / autoresponder | Совпадение ID принималось за ЛС | Явная проверка PRIVATE |
| spam_ban | Группа принималась за личку; /start выдавался за репорт | Тип peer; messages.reportSpam + блокировка; без фиктивной работы твинков |
| mafia_triggers | Отсутствовал заголовок для strncmp | Добавлен cstring |

Общий хост: результат модерации не отправляется как progress-edit до ответа RPC.
При ошибке последующие действия этой команды отменяются, сообщение об успехе
не воспроизводится; в чат выводится ошибка и число завершённых запросов.
В ЛС ban/unban означает contacts.block/contacts.unblock.

Проверки: сборка всех 32 Android `.so`; тесты реестра и ABI, сериализация настоящих
TL-запросов, отдельные регрессии peer-типа и progress-edit. Реальные аккаунты и
права пользователей не менялись. Полная функциональность каждой команды всех
32 модулей на живом Telegram в рамках этой проверки не проверялась.
