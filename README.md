## 🚀 Как установить модули

### Способ 1: Через приложение Kotogram (Рекомендуется)
1. Откройте **Kotogram** на Android и перейдите во вкладку **Модули** → **Репозиторий**.
2. Вставьте ссылку на каталог:
   ```text
   https://raw.githubusercontent.com/AresUser1/KoteModules/main/index.json
   ```
3. Выберите нужный модуль из списка и нажмите **«Установить»**. Модуль мгновенно загрузится и активируется без перезагрузки приложения!

### Способ 2: Через Telegram (команда `.install`)
1. Скачайте файл `.so` из папки [`modules/`](modules/) (например, [`checkers.so`](modules/checkers.so), [`copymessage.so`](modules/copymessage.so) или [`music.so`](modules/music.so)).
2. Отправьте файл себе в «Избранное» или в любой чат как документ.
3. Ответьте на сообщение с файлом командой:
   ```text
   .install
   ```
4. Бот подтвердит установку, и команды сразу появятся в `.help` и `.modules`.

## 🛠 Подробности модулей

### ♟️ Шашки (`checkers.so`)
* **Полноценный PvP между любыми игроками**: запустить партию может любой участник в группе, бот выступает арбитром доски.
* **Выбор стороны**: интерактивное лобби с кнопками выбора цвета. Любой игрок может играть как за белых, так и за чёрных.
* **Серии ударов в 1 клик**: движок рассчитывает всю цепочку обязательных взятий — не нужно нажимать каждый промежуточный прыжок по отдельности.
* **Правила**:
  * Простые шашки бьют назад.
  * Дамки перемещаются и бьют по всей диагонали.
  * Обязательный бой.
  * Пат (если у игрока нет доступных ходов, ему засчитывается поражение).
* **Управление партией**: кнопки согласия на ничью (`🤝 Ничья`), сдачи (`🏳 Сдаться`) и реванша (`🔄 Реванш`).

### 📥 Копирование сообщений (`copymessage.so`)
* Обход запрета на пересылку контента в каналах и закрытых группах (`noforwards`).
* Сохраняет точное форматирование текста, ссылки и кастомные эмодзи.
* Скачивает и пересылает прикрепленные медиафайлы.
* `.hcopy` моментально удаляет команду юзербота, не оставляя следов в исходном чате.

### 🎵 Музыкальный плеер (`music.so`)
* **Поиск и отправка через ботов Telegram (`.mus <запрос>`)**: мгновенная отправка трека напрямую через серверы Telegram без скачивания на память телефона (@lybot → @vkmusic_bot).
* **Управление**: `.musconfig` (статус и конфигурация).

### 🎭 Ролевые команды (`rp.so`)
* **Нативный Role-Play модуль** со встроенной базой из 22 популярных действий (`.обнять`, `.поцеловать`, `.кусь`, `.ударить`, `.погладить`, `.прижать`, `.укусить`, `.похвалить` и др.).
* **Гибкое создание команд (`.addrp`)**: добавление кастомных действий с алиасами и эмодзи (`.addrp кус|кусить|сделать кусь`).
* **Система РП-ников (`.setrpnick`)**: привязка локальных (для чата) или глобальных (`-g`) ников пользователям, отображаемых при выполнении действий.
* **Контроль доступа (`.rp access` / `.addrpcreator`)**: разграничение прав в беседах (все участники, только доверенные, только создатели).
* **Кастомные эмодзи (`.setrpemoji`)**: поддержка статичных и Telegram Premium кастомных эмодзи для каждого действия.

## 👨‍💻 Разработчикам модулей

Все нативные C и C++ модули разрабатываются на базе **Kote Module SDK (ABI 3)**:
* 🧰 **[Скачать Kote Module SDK Kit (ZIP)](https://github.com/AresUser1/LoaderKote/releases/latest/download/kote-module-sdk.zip)** — официальный архив со всеми инструментами сборки, заголовочным файлом `module_abi.h`, кроссплатформенными скриптами `build.sh` / `Makefile` / `build.bat` и подробными руководствами по C и Lua.
* **Сборка под Android**: NDK Clang под `arm64-v8a` (или под локальный Linux через `./build.sh --host`).
* **Инлайн-кнопки и колбэки**: универсальная поддержка интерактивных игр и кнопочных меню через `api->c_button()`, `on_callback`, `api->cb_answer()` и `api->c_edit_message()`.
* **Готовый шаблон**: используйте `src/my_module.c` из архива SDK для быстрого старта.

## Обновление для Kotogram 0.3.40

Проверены все 32 нативных исходника и выполнена NDK-сборка под arm64-v8a / API 26.
Исправлено определение типа чата в administration, moderation, mass_notifier,
banall, RP, Silent Tags, AFK, autoresponder и spam_ban. Обновлённые варианты
используют API ядра **60+**; совместимость указана и в `.so`, и в каталоге.

Шахматы используют обычные Unicode-фигуры. Counter и демонстрационные модули
в каталог не входят. Каталог содержит реальные размеры и SHA-256 бинарников.

`spam_ban` использует настоящий запрос жалобы Telegram и блокировку пользователя.
Отправка `/start` пользователю удалена. Репорт с нескольких твинков не объявляется
рабочим: текущая версия выполняет действие выбранным аккаунтом.

Проверки включают реальные загрузку ABI/реестр, сериализацию MTProto, правила
шахмат, положительные ID групп, пустой кеш и отложенный вывод результатов.
Это офлайн-проверки: действия с участниками реального Telegram-чата не выполнялись.

CI использует публичный снимок SDK в `sdk/`; доступ к приватным исходникам
Kotogram для сборки `.so` не нужен. Полная интеграция запускается в приватном CI ядра.
